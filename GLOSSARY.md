# Inference benchmark

Terms used to describe the image-inspection experiments and their results.

## Language

**Reference set**:
A collection of labeled example images provided to a model for one-shot inspection, with one example per category.

**Repetition**:
Another execution of a benchmark configuration used to observe variation between runs.

**Evaluation set**:
The images whose inspection results are scored in an experiment. Reference images are excluded from the shared evaluation set used to compare shot modes.
