# Transistor detection Guide
## Normal Case (good)
You should see a TO-92 cased electronic component with three leads in a THT circuit board. These three leads should al be put through the via holes at the bottom of the image.
## Failure modes (anomaly)
Failure modes include, but not limited to:
- Beant leads
- Missing (or cut) leads 
- misplaced transistor
- damaged case

If you encounter a prodict which you cannot fit within these categories, you should mark the defect category as "other"
